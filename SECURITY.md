# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Please don't open a public issue.

Include what you found, how to reproduce it, and its impact. You'll get a reply within 7 days, and updates until it is fixed.

## Scope

This repository and the sites it deploys: sulba.dev and its preview addresses.

Please don't access other people's accounts or data, run tests that degrade the service, or use social engineering.

## Supported versions

Only the current deployment from `main` is supported.
