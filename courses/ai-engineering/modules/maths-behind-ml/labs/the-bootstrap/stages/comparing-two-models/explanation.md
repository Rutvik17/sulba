On a resample, the samples both models get right and the samples both get wrong add nothing to the difference. Each sample model a alone gets right adds `$1/n$`, and each one model b alone gets right takes `$1/n$` away, so a resample's difference is `$(c_a - c_b)/n$`, where `$c_a$` and `$c_b$` count those samples among its draws.

Drawing `$n$` samples with replacement, the numbers that land in each of the three groups follow a multinomial distribution, with the groups' shares of the samples as its probabilities. `rng.multinomial(n, shares, size=repeats)` draws those counts directly: three numbers a resample, however many samples there are, so a million samples cost no more to resample than {% $fig.new %}.

For the clinic's two rules, the {% $fig.only_a %} samples only the first gets right and the {% $fig.only_b %} only the second does give a difference of 0, and a 95% interval from {% $fig.low %} to {% $fig.high %} percentage points: on samples like these, either rule could be up to {% $fig.high %} points better. Resampled apart, as if each rule had been tested on samples of its own, the interval would run from {% $fig.unpaired_low %} to {% $fig.unpaired_high %} points. Paired, the {% $fig.agree %} samples on which the rules agree move both accuracies together and cancel. Results from different samples have no pairs to resample, so they can't be compared this way.

When model b is never right where model a is wrong, no resample can put b ahead, and a bootstrap interval starts at 0 or above. A normal approximation, the difference give or take a multiple of its standard error, can start below 0, and put b ahead where no resample can.
