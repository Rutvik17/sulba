A 95% confidence interval is a promise about the method, not about one interval: over all the samples the clinic could draw, intervals made this way cover the true value 95% of the time. Any one interval covers it or doesn't.

For the clinic's accuracy, {% $fig.accuracy %}, the percentile interval runs from {% $fig.low %} to {% $fig.high %}: the resamples' accuracies reach {% $fig.below %} percentage points below the estimate and {% $fig.above %} above it. The basic interval reads the same quantiles another way. It takes the gap between a resample's accuracy and the estimate as a stand-in for the gap between the estimate and the truth, turned around: the resamples fall up to {% $fig.below %} points below the estimate, so the truth may sit up to {% $fig.below %} points above it. The basic interval runs from {% $fig.basic_low %} to {% $fig.basic_high %}.

Neither keeps its promise for every kind of sample. The chart takes the clinic's {% $fig.records %} records as the whole population, whose mean worst area, {% $fig.area_mean %}, is known, and draws {% $fig.samples %} samples at each size. At {% $fig.few %} samples, the percentile intervals covered the mean for {% $fig.percentile_few %} of them and the basic intervals for {% $fig.basic_few %}. At {% $fig.many %}, they covered it for {% $fig.percentile_many %} and {% $fig.basic_many %}.

Worst area is skewed: its median is {% $fig.area_median %}, its largest value {% $fig.area_max %}, and its skewness {% $fig.skew %}. A small sample often misses the few very large masses, and its bootstrap distribution, made only from what the sample holds, is then too narrow and sits too low.
