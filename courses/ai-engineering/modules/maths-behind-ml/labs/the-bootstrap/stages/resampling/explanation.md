A resample treats the sample as if it were every sample the clinic could see: it draws `$n$` rows from it with replacement, the way the sample itself was drawn. So the accuracy varies over resamples about as it would over new samples of {% $fig.new %}, and the bootstrap distribution's standard deviation estimates the accuracy's standard error. Each resample leaves out about `$(1 - 1/n)^n$` of the rows, {% $fig.left_out %} for {% $fig.new %}, and uses others more than once.

For a share there is a formula to compare with. The accuracy is the share of the {% $fig.new %} samples the rule gets right, and a share `$p$` of `$n$` has a standard error of `$\sqrt{p(1 - p)/n}$`, {% $fig.formula %} here. The bootstrap gives {% $fig.se %} over {% $fig.repeats %} resamples, without the formula. For a median there is no formula as simple, and the bootstrap works the same way: the new samples' median worst area, {% $fig.median_area %}, has a standard error of {% $fig.median_se %}.

The chart shows the accuracy on each resample. The rule is right on a whole number of the {% $fig.new %} samples in a resample, so the accuracies fall on those steps. With few resamples their shape is rough, and with {% $fig.repeats %}, SciPy's default, it settles.
