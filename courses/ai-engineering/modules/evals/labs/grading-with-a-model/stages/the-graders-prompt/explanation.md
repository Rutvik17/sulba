The template is {% $fig.template_lines %} lines of jinja2. For a reply and its context, it writes a system turn with the date, then a user turn that sets the grader's task, quotes the context and the reply, defines the risk of a message not grounded in its context, and asks for `Yes` or `No`, then opens the grader's turn. Rendering it from IBM's own file keeps the prompt the one the model was trained on, word for word, and a change to the template reaches the help desk with the model.

The grader's word is a verdict, but its probability is a score: one that can be ranked, compared with people's labels at every threshold, and set to the threshold the help desk chooses. The probabilities of the two words don't sum to 1, since a little of the first token's probability goes to other tokens, so the score is `Yes`'s share of the two. The date is the one thing in the prompt that changes from day to day, so a grade recorded with one date is given again with the same date.
