An inversion of a list is a pair of places `i < j` with `numbers[i] > numbers[j]`. Write `inversions`:

```
inversions(numbers) -> how many inversions the list has
```

`inversions([2, 4, 1, 3, 5])` returns 3: 2 and 1, 4 and 1, and 4 and 3. Equal numbers aren't an inversion. The tests' longest list has {% $fig.numbers %} numbers.
