The Fibonacci numbers start with 0 and 1, and each one after is the two before it added: 0, 1, 1, 2, 3, 5, 8 and on, with `F(0)` the first. Write `fibonacci`:

```
fibonacci(n, modulus) -> F(n) % modulus
```
