The port's tests so far have been the lab's own. The service needs its own: `test_typed.py`, pytest tests of `typed.py` kept beside it, so a change that breaks a struct fails a test before it's merged. Hidden tests run yours against the port, and against copies of it, each broken in one place the way a change could break it. Yours should pass on the port and fail on every copy, so test what each struct lets through and what it stops: `number` with `True`, `False` and NaN, `array` with more than one item and with values that aren't lists, `nullable` with `None`, and `create`'s message in full.

pytest runs each function whose name starts with `test` in a file whose name does too. A plain `assert` is the check: when one fails, pytest shows both sides of the comparison. `@pytest.mark.parametrize("value", [17.99, 3])` above a test runs it once for each value, passed as its `value` argument. `with pytest.raises(StructError) as raised:` passes when its block raises a `StructError`, or an error of a subclass, and fails when the block raises nothing; `raised.value` is the error.
