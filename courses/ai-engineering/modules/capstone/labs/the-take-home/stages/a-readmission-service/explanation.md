`stays` keeps each patient's first encounter, and leaves out the stays that ended in death or hospice care, as the study behind the extract did: {% $fig.stays %} stays, {% $fig.readmitted %} of them, {% $fig.rate %}, readmitted within {% $fig.days %} days. With one stay for each patient, no patient has stays on both sides of a split, so the held-out stays come from patients the model hasn't seen. Reading `None` as written keeps a test not done apart from a missing value, and a request sends the same `None`.

`train` keeps the encoding inside the model, in a pipeline: a `ColumnTransformer` scales the counts and one-hot encodes the categories, then a logistic regression. The codes are categories too, since a code's number is a label, not an amount. Fitting the pipeline learns each count's mean and spread, and each category's values, from the training stays, and `predict_proba` puts a row through the same steps, so a request is encoded as the training stays were. With `handle_unknown="ignore"`, a value the model never saw is encoded as none of the values it knows, rather than raising an error.

`app` trains its model once, when `service.py` is imported, so a request only encodes one row and scores it. `Stay` lists the request's fields with their types: FastAPI reads each request's JSON into it before `predict` runs, and answers a 422 for one that doesn't fit, with a `detail` naming each field that's missing or can't be read. `predict` is `async def` since it waits on nothing, so FastAPI runs it on its event loop, without a thread.

On the {% $fig.held_out %} held-out stays, the model's AUC is {% $fig.auc %}, where a model that gives every stay the same answer, such as always no readmission, gets {% $fig.constant_auc %}. On {% $fig.splits %} other random splits of the stays, it ranges from {% $fig.auc_low %} to {% $fig.auc_high %}: a held-out set's AUC is an estimate, and each split gives a different one. Its probabilities average {% $fig.mean_probability %} over the held-out stays, and {% $fig.held_out_rate %} of those stays were readmitted, so on average its chances match how often the stays were readmitted. Trained with the readmissions weighted up, with `class_weight="balanced"`, the same model ranks the held-out stays about as well, at {% $fig.weighted_auc %}, but its probabilities average {% $fig.weighted_mean %}, far above how often the stays were readmitted.
