`Upstream` is an interface, and nothing has to declare that it implements one. Effective Go: "Interfaces in Go provide a way to specify the behavior of an object: if something can do this, then it can be used here." Any type with a `Name` and a `Chat` of the right shape is an `Upstream`, so the tests' fake, the HTTP client the gateway will have, and anything that wraps one can share a list. The tests' fake counts its calls through a pointer receiver, `func (f *fake) Chat(...)`, so the count lands in the one fake the test holds. Effective Go gives the rule that follows: "value methods can be invoked on pointers and values, but pointer methods can only be invoked on pointers." Only `*fake` is an `Upstream`, so the list holds `&fake{...}`.

Which errors to retry comes from what each status means. RFC 9110: "The 4xx (Client Error) class of status code indicates that the client seems to have erred." A 400 from one upstream is the request's fault, and every upstream would refuse it. "The 5xx (Server Error) class of status code indicates that the server is aware that it has erred or is incapable of performing the requested method": that's one server's trouble, which the next may not share. A 429 is an upstream with too much to do, and an upstream's own time limit means that upstream was slow.

A `context.Context` carries the caller's deadline and cancellation into each call it's passed to. The context package asks that it be "the first parameter, typically named ctx", and says what `Err` gives: nil until the context is done, then "DeadlineExceeded if the context's deadline passed, or Canceled if the context was canceled for some other reason." An upstream that ran out of the caller's time gives that same `DeadlineExceeded`, which is retryable, so it's the check of `ctx` before the next upstream that ends the loop. A caller that has gone stops the gateway asking on its behalf.

`errors.Join` keeps every upstream's error in one, and its docs promise "The errors may be inspected with Is and As", so a caller can still ask whether any of them was a 429.
