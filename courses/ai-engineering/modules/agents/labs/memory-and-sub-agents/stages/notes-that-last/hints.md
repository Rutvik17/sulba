A subclass of `Memory` can read the caller's notes when it starts and write them whenever `note` or `forget` changes them.

---

Try the caller ids `"a"`, `"../a"` and `"a/"` against your file names: which of them name the same file, and which leave the folder?

---

Each note goes into every request after it, so check the limits before the note is kept, not after.
