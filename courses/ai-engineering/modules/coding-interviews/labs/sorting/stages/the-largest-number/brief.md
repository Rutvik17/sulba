Write `largest_number`, for a list of one or more whole numbers of `0` or more:

```
largest_number(numbers) -> the largest number that writing all of numbers side by side, in some
    order, can make, as a string
```

`largest_number([7, 75, 761, 2])` returns `"7761752"`. When every number is `0`, the answer is `"0"`, not `"00"`.
