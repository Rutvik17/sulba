A list holds each day's temperature, in order. Write `days_until_warmer`:

```
days_until_warmer(temperatures) -> for each day, how many days until a warmer one, or 0 if no
    warmer day comes
```

`days_until_warmer([18, 16, 17, 21, 19, 18, 22])` returns `[3, 1, 1, 3, 2, 1, 0]`. A day as warm, not warmer, doesn't count.
