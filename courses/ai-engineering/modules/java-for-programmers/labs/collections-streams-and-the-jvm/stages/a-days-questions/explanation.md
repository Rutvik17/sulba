A stream is Java's pipeline over a collection, like a chain of generator expressions in Python. The `java.util.stream` docs say a stream "is not a data structure that stores elements; instead, it conveys elements from a source", and that "an operation on a stream produces a result, but does not modify its source." So `log.stream().map(Asked::reply).sorted()` sorts the replies in the stream and leaves the caller's log in its own order, where `Collections.sort(log)` would have reordered it, or thrown for a list that can't change. A stream is also "consumable": "a new stream must be generated to revisit the same elements of the source."

Collectors do what Python's `Counter` and `itertools.groupby` do between them. `groupingBy(classifier, mapFactory, downstream)` returns "a Collector implementing a cascaded "group by" operation": the classifier gives each element's key, the map factory is "a supplier providing a new empty Map" to put the groups in, and the downstream collector reduces each group, here with `counting()`. The map factory decides the order. A plain `groupingBy` gives a `HashMap`, in no promised order, while an `EnumMap` gives the services in the order the enum declares them and a `TreeMap` gives the hours from 0.

A comparator chain is Java's sort key. Python sorts the pages with `key=lambda page: (-page.questions, page.name)`, and Java builds the same order from parts: `comparingLong(PageCount::questions)` by count, `reversed()` for the most first, and `thenComparing(PageCount::page)` for ties by name. `reversed()` "returns a comparator that imposes the reverse ordering of this comparator", the whole chain built so far, so calling it last would turn the names around too. `limit(n)` takes the first `n`, and it throws "if maxSize is negative", which is the `IllegalArgumentException` the brief asks for.

`medianReply` returns an `Optional<Duration>` because an empty log has no median, and Java code returns an empty `Optional` where Python returns `None`, so the caller's type says to check. A `Duration` adds and divides as an amount of time, so the mean of 5 and 6 seconds is 5.5 seconds, not a number rounded to whole seconds.

An `Instant` is a point on the timeline, and an hour of the day exists only on a clock in some place. `ZoneId` "is used to identify the rules used to convert between an Instant and a LocalDateTime", and `America/New_York` is a "geographical region", whose offset from UTC changes with the date. New York's clocks went back on Sunday 1 November 2026, so 13:30 UTC was 9:30 on the Friday before and 8:30 on the Monday after. A fixed offset such as `-04:00` would have put Monday's questions an hour late.
