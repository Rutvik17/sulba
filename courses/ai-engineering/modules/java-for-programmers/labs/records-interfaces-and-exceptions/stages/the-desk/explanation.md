Java's lists and maps, like Python's, are objects that every holder shares. A `Desk` that kept the list it was given would change whenever the caller who made it changed that list, and a desk that handed out its own list would let any reader clear it. So the desk copies on the way in and on the way out. `List.copyOf` gives "an unmodifiable List containing the elements of the given Collection", and of such lists, `List`'s docs say: "Elements cannot be added, removed, or replaced. Calling any mutator method on the List will always cause UnsupportedOperationException to be thrown." A copy of the outer map alone wouldn't do: its values would still be the caller's own maps and lists, so the desk copies each level. The tickets inside need no copying, since a record can't change.

The free times are kept in a `TreeSet`, whose elements are "ordered using their natural ordering", which for `LocalTime` is the order of the day. A time freed by a cancel goes back in its place, with no sort to remember. The services are kept in an `EnumMap`, "a specialized Map implementation for use with enum type keys", which keeps them in the order the enum declares them.

The desk refuses with a checked exception, which is the kind Python doesn't have. The Java Language Specification says "the checked exception classes are Throwable and all its subclasses other than RuntimeException and its subclasses and Error and its subclasses", and the compiler holds every caller to them: "For each checked exception which is a possible result, the throws clause for the method or constructor must mention the class of that exception or one of the superclasses". So code that calls `bookCallback` either catches `Refused` or says it throws it, and the tools in the next stage can't forget that a booking can fail. Java's tutorial puts the rule for choosing: "If a client can reasonably be expected to recover from an exception, make it a checked exception. If a client cannot do anything to recover from the exception, make it an unchecked exception." A time that's taken is a case the desk's caller recovers from, by offering another time. A blank summary, which `Ticket` refuses with an unchecked `IllegalArgumentException`, is a mistake in the calling code.

`openTicket` makes the ticket before it counts it. If the order were the other way, a summary the ticket refused would use up `T-3001`, and the next ticket the caller opened would skip it.

`cancelCallback` finds the callback with `remove`, which removes an element equal to the one it's given. A record's `equals` compares every part, so `new Callback(ticket, day, time)` finds the callback booked with that ticket, day and time.

A `LocalTime` writes itself in "the shortest that outputs the full value of the time where the omitted parts are implied to be zero", so `09:00`, which the messages use. Jackson writes it with seconds unless told otherwise, as `09:00:00`, and `@JsonFormat(pattern = "HH:mm")` tells it.
