`heights` is a grid of heights, a list of rows. A climb moves up, down, left or right, each step to a strictly higher square. Write `longest_climb`:

```
longest_climb(heights) -> how many squares the longest climb visits
```

`longest_climb([[9, 9, 4], [6, 6, 8], [2, 1, 1]])` returns 4: 1, 2, 6 and 9. The tests' largest grid is {% $fig.side %} by {% $fig.side %}, and its longest climb visits every square.
