A host reaches the desk over the container's network, so the desk listens on every address. uvicorn's own default is "Default: '127.0.0.1'", which only the machine itself reaches. Render's documentation: "Every Render web service must bind to a port on host 0.0.0.0 to serve HTTP requests", and "We recommend binding your HTTP server to the port defined by the PORT environment variable." Its default for `PORT` is 10000, so the desk takes the port it's given and keeps 8000 for a machine that gives none.

Behind a host's proxy, every request comes from the proxy, which says who the caller was in `X-Forwarded-For`. Anyone can send that header, so uvicorn believes it only from the addresses it's told to trust. Its documentation: "Only trust clients you can actually trust!" and "Incorrectly trusting other clients can lead to malicious actors spoofing their apparent client address to your application." The desk trusts the machine itself unless `FORWARDED_ALLOW_IPS` names the host's proxies.

Hosts stop a process by sending it SIGTERM, then end it a while later: Render waits "its specified shutdown delay (default 30 seconds)" before it "sends a SIGKILL signal to force the process to terminate." On SIGTERM, uvicorn stops taking connections and waits for the open ones, and with no limit it waits for every reply to finish, which can take the desk's two minutes. With `timeout_graceful_shutdown` at 25, it cancels what's still open after 25 seconds, then runs the app's shutdown, which closes the database's pool and the model's client, before the host's kill comes.

`log_config=None` keeps uvicorn's own lines, such as `Shutting down`, going through the desk's JSON handler, where uvicorn's default settings give them handlers of their own. The desk's request line, with its id, takes the place of uvicorn's access log.
