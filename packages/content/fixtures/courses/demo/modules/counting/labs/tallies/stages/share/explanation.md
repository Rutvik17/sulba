A share is a count divided by the total. Written out for the poll's {% $fig.votes %} votes:

```math
\operatorname{share}(\text{yes}) = \frac{\operatorname{count}(\text{yes})}{n} = \frac{[\, x_1 = \text{yes} \,] + [\, x_2 = \text{yes} \,] + [\, x_3 = \text{yes} \,]}{\fig{votes}} = \frac{\fig{yes}}{\fig{votes}}
```
