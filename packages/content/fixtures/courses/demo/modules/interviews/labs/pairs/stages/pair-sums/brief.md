Write `pair_sum`, which returns the positions of the two numbers in `numbers` that add up to `target`, the earlier position first, or `None` if no two numbers do. A number can't pair with itself. `pair_sum([3, 9, 4, 7], 11)` returns `(2, 3)`.

Each list in the tests has one such pair at most, and the longest has a hundred thousand numbers.
